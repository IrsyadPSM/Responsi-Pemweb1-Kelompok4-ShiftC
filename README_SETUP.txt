CARA MENJALANKAN
1. Salin folder "siskamling" ke C:\xampp\htdocs\
2. Start Apache dan MySQL di XAMPP
3. Import siskamling_digital.sql lewat phpMyAdmin (tab SQL)
4. Buka http://localhost/siskamling/login.php
   Akun contoh: admin / password  |  ketua / password  |  budi / password

CATATAN
- Mengulang dari data awal: jalankan DROP DATABASE IF EXISTS siskamling_digital; di tab SQL, lalu import ulang siskamling_digital.sql
- Disarankan PHP 8.1 atau lebih baru. Panduan lengkap ada di README.md
